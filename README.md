### ⚙️ Current Focus: Low-Level Systems Architecture

Currently engineering a custom operating system for ARM64 devices from scratch. 
* **Core Technologies:** Rust, C.
* **Key Implementations:** Bare-metal boot protocols, UART drivers, VGA drivers, and exception dispatchers.
